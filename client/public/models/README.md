# 3D Nurse Models Directory
Place your 3D GLB/GLTF model file at:
`client/public/models/nurse.glb`

The `NurseModel.jsx` component will automatically load `/models/nurse.glb` with auto-scaling, auto-centering, and animation playback.
If no `.glb` file is present, the component automatically falls back to our procedural 3D nurse character.
